Installation Guide for Google Chrome & Microsoft Edge

  1. Open your browser and navigate to chrome://extensions (or edge://extensions).
  2. Enable the Developer mode toggle in the top-right corner.
  3. Click Load unpacked in the top-left corner.
  4. Select the repository root folder (Vol-Strike-Cal).
  5. Open TradingView Options Volume — the extension automatically streams real-time prices, options volume, and implied volatility to compute live 1SD/2SD/3SD bands and the Vol Term Structure.
